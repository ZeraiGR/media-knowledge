# Media Knowledge

Личная библиотека аудио и видео с тайм-кодами, виртуальными фрагментами,
офлайн-поиском и локальными ответами по материалам. Выбранными записями и подборками
можно делиться через веб-плеер без регистрации получателя.

Приложение проектируется для macOS, Windows, Android и iOS. VPS управляет
метаданными и доступом. Медиа загружаются напрямую в S3 и воспроизводятся из него.
Транскрипция, подготовка записей и RAG выполняются на компьютере владельца.

## Состояние проекта

Подготовлены четыре публичных репозитория, CI/CD и инфраструктурные приложения.
Go API с PostgreSQL и веб-клиент развёрнуты на VPS через GitHub Actions и доступны
через Tailscale. Flutter-клиент проверяет выпуски и подключается к закрытому API.
Библиотека, синхронизация, плеер и локальный ИИ пока не реализованы.
Закрытый S3-бакет подключён на инфраструктурном уровне. Проверены прямые
загрузка и частичное чтение с Mac и из браузера. Постоянный ключ хранится только
на VPS, прикладная выдача S3-ссылок ожидает реализации авторизации.

[Общий GitHub Project](https://github.com/users/ZeraiGR/projects/1) связывает
[Flutter-клиент](https://github.com/ZeraiGR/media-knowledge-client),
[сервер](https://github.com/ZeraiGR/media-knowledge-server) и
[веб-клиент](https://github.com/ZeraiGR/media-knowledge-web).
Инструкции выпуска и ограничения платформ находятся в
[руководстве по инфраструктуре](docs/infrastructure.md).

## Границы первой версии

Одна личная библиотека владельца, несколько его устройств, публикации только для
просмотра по ссылке. Telegram не интегрируется. На телефоне работает поиск по
синхронизированным текстам. Локальная генерация ответов доступна на компьютере.
Совместное редактирование несколькими пользователями и анализ движений по видео
не входят в первую версию.

## Сопровождение

Изменения поведения сопровождаются обновлением технических документов и личного
портала по [общему стандарту](https://github.com/ZeraiGR/personal-docs/blob/main/src/content/docs/docs/project-standard.md).
Исходники содержат только синтетические примеры. Записи, транскрипции владельца,
модели, рабочие базы, ключи и адреса инфраструктуры в Git не добавляются.
